# juleik

Website von Julia Eikermann, gebaut mit HTML, CSS und etwas JavaScript.

## Struktur

- `index.html` – Startseite
- `kontakt/index.html` – Impressum und Datenschutzerklärung
- `style.css` – Styling
- `script.js` – mobiles Menü
- `img/` – Bilder
- `fonts/` – lokal eingebundene Schriften

## Lokal starten

```sh
python3 -m http.server 8000
```

Danach `http://localhost:8000` im Browser öffnen.
